# Gloamreach — releases

Builds of **Gloamreach**, a dark, slow, top-down pixel souls-like with 2-player online co-op.

**Get the newest build:** open [Releases](../../releases/latest).
- **Windows:** download `Gloamreach-windows.zip`, unzip it, and run `Gloamreach.exe`. If SmartScreen warns you, click *More info → Run anyway*. The game isn't code-signed.
- **Android:** download `Gloamreach.apk` on your phone and open it. The first time, Android asks you to allow installs from your browser.

The game checks this page every time it starts. New content downloads automatically, so you only install again when the game tells you to.

Logs, for bug reports: press **F8** in game, or tap **Log** in the menu, then **Copy this log**.
